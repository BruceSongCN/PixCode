# 代码注释与提交

## 中文注释

- Agent 自动新增或修改的源码注释、文档注释，以及 `TODO`、`FIXME` 等说明性注释，必须使用中文编写。
- 代码标识符、API 名称、协议名、库名和无法准确翻译的技术术语可以保留原文，必要时使用反引号标识。
- 修改已有注释时，修改后的完整注释应符合中文要求；不要求批量翻译本轮未触及的历史注释。
- 自动生成文件、第三方或上游代码，以及必须保持原文的引用内容不受此规则约束。

## 自动提交门禁

- Agent 自动暂存或提交代码前，必须检查本轮差异中新增和修改的注释。
- 若发现新增或修改的说明性注释仍以英文编写，应先改为中文，再执行暂存或提交。
- 字符串常量、日志、异常消息、协议字段和测试数据不属于代码注释，不因本规则强制翻译。
- 目标仓库存在更严格的注释规范时，遵循更严格的规则。
